# helix-platform

Helix — Intelligence Designed To Evolve

Modular AI platform — Reason / Adapt / Collaborate. Built with Next.js 16.3.3 + Tailwind CSS 4.3 + React 19.

## Stack
- Next.js 16.3.3 (App Router, Turbopack)
- React 19.1 + TypeScript 5.7 strict
- Tailwind CSS 4.3.3 via @tailwindcss/postcss

## Commands
``n npm run dev     # next dev
 npm run build   # next build (primary verification)
 npm run lint    # next lint
``n
## Structure
- app/layout.tsx — Helix branding, Inter + Geist Pixel Circle
- app/page.tsx — Hero video stage + Stats + Products
- components/Header.tsx — fixed navbar
- components/Hero.tsx / Stats.tsx / Products.tsx
